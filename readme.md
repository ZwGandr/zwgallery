# Zw Gallery

This is the front-end service for [Zw Gallery](https://gallery.zwgandr.cn), 
adapted from [Boar Gallery](https://gallery.boar.osaka).

It has to work with the specific backend, which is not yet open source.

The map layout follows [Bokufa's Nihon Saien](https://gallery.bokufa.art/map). The U.S. and mainland China administrative
boundaries come from the public-domain [Natural Earth 1:50m Admin 1 dataset](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_50m_admin_1_states_provinces.geojson).
